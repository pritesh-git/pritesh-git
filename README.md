### 👨‍💻 Professional Background & Engineering Journey

- 💻 **13+ Years in Code**: Began exploring software in 2013 on a desktop computer, discovering how code interfaces with memory through C and C++ (pointer arithmetic, manual allocation), early web scripting (HTML, JSP, PHP), and desktop GUI applications (VB.NET).
- 🎓 **Academic Foundations**: Completed a Bachelor's degree (2016–18) focusing on ECMAScript standards, DOM architecture, and TypeScript, followed by a Master's degree (2018–20) centered on component lifecycles, React, Express microservices, and PHP MVC frameworks (Laravel, CodeIgniter).
- 🛡️ **The QA Crucible**: Began professional career in React development before taking ownership of comprehensive enterprise quality assurance across multiple production systems—architecting deterministic, resilient end-to-end and integration test suites using **Cypress, Playwright, Jest, React Testing Library, and Selenium**.
- 🚀 **Senior Multi-Framework Development**: Transitioned into senior development across diverse ecosystems (React, Angular, Stencil.js, Astro.js), distributed WebSockets, cloud infrastructure, and 3D web graphics. **Currently actively shipping production systems in Vue 3**.
- 🐧 **Operating System**: Daily driver is **Ubuntu Linux** (journeyed from Windows → macOS → Ubuntu).
- 💬 **Ask me about**: Full-stack web architectures, Vue 3 reactivity & Composition API, React Fiber internals, test automation strategies, and high-concurrency real-time systems.
